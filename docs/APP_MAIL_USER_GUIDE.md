# 運営からのお知らせと登録完了メール

運営アカウントのメニュー「お知らせ・メール配信」から操作します。
差出人は「声のフリマ運営 <support@koe-furima.com>」です。個人のGmailや他の利用者の宛先は表示しません。メールの詳細にはサービス専用アドレスが表示されます。

## 全体へのお知らせ

1. 件名・本文を入力し、下書きを保存します。
2. 送信対象人数を確認し、自分宛てのテストメールを確認します。
3. 最後の確認後に、アプリ掲載と対象者への配信を開始します。

内容を編集した場合は保存とテストをやり直します。登録メールの確認が済んでいない方、利用停止・削除済みの方、配信を停止している方には送りません。サービス運営に関するお知らせ専用です。全体へのテスト配信は行いません。

## 登録完了のお礼

丁寧な敬語のお礼メールを、メール確認まで完了した登録者へ1回だけ送る機能です。最初は停止状態です。運営本人宛てのテストを確認してから有効にします。既存の確認済みアカウントへ一括送信はしません。

## 通知設定と結果

利用者はメニュー「メール通知」から運営のお知らせメールの配信を変更できます。アプリ内のお知らせは引き続き確認できます。

「送信受付」は配信サービスが受け付けた状態です。「宛先サーバー到達」でも受信トレイへの振り分けや閲覧までは保証しません。結果未確認のメールを作り直して重ねて送らず、配信状況をご確認ください。

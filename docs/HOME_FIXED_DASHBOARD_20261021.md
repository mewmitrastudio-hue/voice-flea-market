# 画像の配置を基準にホームを固定

本人指定のIMG_5861.jpegの並びを維持し、ホーム全体が収まる場合はスクロールを無効にする。上部ロゴ、4つの操作ボタン、ホーム/使い方、見出し、2列の機能カード、案内、2列の利用状況、下部ナビの順は変えない。

ホーム内を5行のgridにし、余白を6px間隔へ整理。機能カードの2行へ残りの高さを配分する。文字の縮小やtransformによる画面縮小は行わない。

小画面、文字拡大、案内を展開した場合など、実際のscrollHeightが表示高を超える場合だけスクロールを許可して、内容を切り捨てない。ResizeObserverで表示領域と各ブロックを測り直す。画面が広がって再び収まれば固定へ戻す。他画面のスクロール方式は変更しない。

全22テストとビルド19のCapacitor同期・ハッシュ検証に成功。固定/超過時の到達可能性/再固定/非表示時の保持の振る舞いを検証済み。ただしWKWebView上で指定画像と同じ見た目・固定状態になることは実機での確認が必要。自動テストで実機の見た目を確認したとは扱わない。

# ホーム見出しの欠けへの対応

ビルド17のiPhone画像で、ホーム見出しの上端が切れていることを確認。
通常画面は `.page.on` 内をスクロールするが、画面移動の `go()` は親 `.app` とwindowしか先頭に戻していなかった。ホームのスクロールが27px残った状態から他の画面を開いて戻ると、27pxがそのまま残る問題を本番関数を実行するテストで再現した。

表示先のページのscrollTopもリセットするよう修正。明示的なkeepScrollは維持し、メッセージのスクロール動作も維持する。配色、文字サイズ、価格、ブースト順位は変更しない。

修正前は再現テスト2件が失敗し、修正後は3件とも成功。全18テスト、ビルド18でのCapacitor同期とソースハッシュ検証が成功。
これはスクロール保持の不具合を再現・修正した結果であり、提供画像の状態とWKWebView実機上の修正後表示が完全に一致することはまだ未確認。実機でホーム表示、下へスクロール後の他画面往復、使い方を閉じた後のホーム操作を確認する。

リリース2026.10.21-2、ビルド18以上。App Review再提出・一般公開は行わない。
